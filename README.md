# MFCApplication17

> 一个看起来有点“像是未来感桌面应用”的 MFC 工程，融合了可视化界面、脚本执行能力和数学表达式处理逻辑，像给 Windows 桌面编程披上了一层轻盈而有灵魂的外衣。

## ✨ 项目简介

MFCApplication17 是一个基于 Microsoft Foundation Classes (MFC) 的 Windows 桌面应用示例项目。它不仅是一个传统的 GUI 程序，更像是一个“可交互的实验室”——你可以在其中观察变量、表达式、数组、函数和脚本控制流如何在界面中协同工作。

如果你喜欢把“工程感”和“可玩性”放在一起，这个项目会非常有意思：一边是规范的 MFC 界面结构，一边是带有脚本引擎的动态执行能力，整体风格偏实用、偏学习、也偏有一点探索欲。

---

## 🚀 这个项目能做什么

这个项目目前已经具备了几个很有代表性的能力：

- 基于 MFC 的桌面应用框架，适合做 Windows 平台下的可视化工具
- 支持多文档界面（MDI）风格窗口组织
- 提供输出窗口、属性窗口、富文本编辑面板等常见 UI 组件
- 内置脚本执行引擎，支持基础的逻辑与计算流程
- 支持变量、表达式、数组、函数、条件判断、循环与输出操作
- 具备类型管理能力，可处理数值、字符串以及通用类型
- 支持在运行时更新相关信息，并将状态同步到应用界面

换句话说，它不是“只会跑起来的 Hello World”，而是一个带一点“思考能力”的小型桌面应用骨架。

## 🧠 项目亮点

### 1. MFC 经典框架，适合入门与进阶

MFC 仍然是 Windows 桌面开发中非常经典的路线之一。这个项目使用了典型的 MFC 文档/视图结构、主窗口框架和子窗口管理方式，适合想要系统学习桌面应用开发的人。

### 2. 脚本引擎不是摆设

项目里包含了一个相对完整的脚本执行器，支持：

- 变量声明与赋值
- 表达式求值
- 条件判断
- 循环控制
- 输出语句
- 函数定义与调用
- 数组创建与操作
- 类型转换
- 状态更新

这意味着它不只是一个界面示例，而是一个“带计算能力的应用内核”。

### 3. 结构清晰，适合二次开发

项目里的源码按模块划分得比较清楚，便于你继续扩展：

- 主窗口与文档框架
- 视图与界面组件
- 脚本语言解析与执行逻辑
- 数学表达式与变量管理
- 输出、属性、编辑等辅助面板

如果你想把它改造成一个更像“编程教学器”或者“公式计算工具”的产品，这个项目已经提供了很好的起点。

## 📁 项目结构

```text
MFCApplication17/
  ├── ChildFrm.cpp / .h           # 子窗口框架
  ├── MainFrm.cpp / .h            # 主窗口框架
  ├── MFCApplication17.cpp        # 应用入口
  ├── MFCApplication17Doc.cpp     # 文档类
  ├── MFCApplication17View.cpp    # 视图类
  ├── script.cpp / .h             # 脚本引擎实现
  ├── Coordinate.cpp / .h         # 坐标/绘图相关逻辑
  ├── MathExpression.cpp / .h     # 数学表达式处理
  ├── Variable.cpp / .h           # 变量管理
  ├── Resource files              # 图标、菜单、对话框资源
  └── res/                        # 资源文件目录
```

## ▶️ 如何运行

### 环境要求

- Windows 操作系统
- Visual Studio 2019 或更高版本
- 已安装 C++ 桌面开发工作负载
- MFC 支持

### 编译步骤

1. 打开解决方案文件：
   - MFCApplication17.sln
2. 选择合适的配置（例如 Debug / x64）
3. 生成解决方案
4. 运行生成出的可执行文件

如果你使用的是 Visual Studio 2022，通常直接按 F5 即可启动项目。
